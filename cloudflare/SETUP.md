# Бесплатное подключение ИИ к «Аксиоме»

Сайт остаётся на GitHub Pages. Cloudflare выполняет только запросы к ИИ. Учителям и ученикам не нужен аккаунт. Владельцу нужен бесплатный аккаунт Cloudflare и одноразовое подключение репозитория.

## 1. Создайте Worker из существующего репозитория

1. Откройте [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **Create application** → **Import a repository** / подключение GitHub.
2. Разрешите Cloudflare доступ к репозиторию **mbulp123-eng/axioma-math-board** и выберите его. Если репозитория нет в списке, измените разрешённые репозитории приложения Cloudflare в GitHub.
3. Укажите настройки:

| Поле | Значение |
| --- | --- |
| Project / Worker name | `axioma-ai` — как в `wrangler.jsonc` |
| Production branch | `main` |
| Root directory | корень репозитория `/` |
| Build command | оставить пустым |
| Deploy command | `npx wrangler deploy` |

4. Нажмите **Deploy**. Дождитесь успешной публикации. При первом запуске Cloudflare может предложить выбрать поддомен `workers.dev`.

Нужен именно **Worker с импортом Git**, а не статический Pages-проект и не загрузка одного JS-файла: `worker.js` импортирует `ai-core.js`, а `wrangler.jsonc` подключает AI и ограничитель частоты.

При импорте Cloudflare сам создаёт токен для сборки. Не вставляйте API-ключи в `app.js`, `ai.js` или `ai-config.js`. Сервер использует привязку `env.AI`; ключ модели в репозитории не нужен.

## 2. Подключите адрес к доске

1. Скопируйте публичный адрес вида `https://axioma-ai.ВАШ-ПОДДОМЕН.workers.dev` из карточки Worker. Это не секрет.
2. Откройте этот адрес. Должен появиться JSON с `service: "axioma-ai"` и `ready: true`. Это проверяет наличие привязок, но ещё не проверяет саму модель.
3. В корневом `ai-config.js` замените пустую строку адресом Worker без пути `/api/assist`:

```js
export const AI_ENDPOINT = 'https://axioma-ai.ВАШ-ПОДДОМЕН.workers.dev';
```

4. Сохраните изменение в `main`, дождитесь успешного GitHub Pages deployment и обновите сайт. Если браузер держит старую версию, используйте Ctrl+Shift+R.
5. Проверьте текстовый запрос, фотографию и перевод. Например: выделите `Решите x + 2 = 5`, создайте три похожих задания, затем запросите подсказку. В переводе проверьте, что формула не изменилась. Только после этих проверок можно считать модель подключённой.

Адрес Worker можно просто передать помощнику, который обновляет этот репозиторий. Пароли и API-токены передавать не нужно.

## Что означает «бесплатно»

На момент подготовки Cloudflare предоставляет Workers AI Free **10 000 Neurons в день на аккаунт**. Это единицы вычислений, а не 10 000 сообщений. Квота общая для посетителей и других AI-приложений владельца; текст и фотографии расходуют её по-разному. Обновление — в 00:00 UTC. На Free после её исчерпания новые запросы не выполняются. Для сохранения нулевых расходов оставайтесь на Free; переход на Paid меняет условия тарификации.

Модель: `@cf/google/gemma-4-26b-a4b-it`, поддерживающая текст и изображения. Сервер ограничивает входной размер, число выходных токенов и частоту запросов. Привязка `AI_RATE_LIMITER` разрешает примерно 5 запросов в минуту на IP в одной точке обработки Cloudflare. Это не строгая глобальная квота; пользователи одной школьной сети могут разделять IP. CORS разрешает браузерные запросы с `https://mbulp123-eng.github.io`, но не является защитой от ботов. Бесплатная квота не гарантирует постоянную доступность публичного ИИ.

При ошибке или исчерпании квоты пользователь получает сообщение. Шаблонный генератор, рисование, сохранение и остальные инструменты доски продолжают работать независимо от AI.

## Настройки и данные

- `wrangler.jsonc` уже содержит Worker name, AI binding и rate limiter. Если сайт переедет на другой домен, измените `ALLOWED_ORIGIN` на origin нового сайта (с протоколом, без пути).
- Приложение не пишет задания/фотографии в свою серверную базу и не выводит их в журнал. Для обработки они передаются Cloudflare. Нельзя считать это локальным/offline-ИИ. См. [правила обработки данных Cloudflare](https://developers.cloudflare.com/workers-ai/platform/data-usage/).
- Нераспознанные места должны отмечаться `[неразборчиво]`; учитель исправляет результат до вставки. Модель может ошибиться и без такой отметки.
- Закрытие панели или отмена прерывает ожидание в браузере. Уже отправленный запрос может завершиться на сервере и расходовать квоту.
- Не переключайте Worker на платный тариф ради сообщения об ошибке. Сначала проверьте модель, лимит и привязки.

## Если не работает

| Сообщение | Что проверить |
| --- | --- |
| «ИИ ещё не подключён» на доске | Публичный адрес в `ai-config.js` и публикацию GitHub Pages |
| `ready: false` у Worker | Публикацию из корня с `wrangler.jsonc`, наличие `AI` и `AI_RATE_LIMITER` |
| «Источник запроса не разрешён» | `ALLOWED_ORIGIN`: для этого сайта `https://mbulp123-eng.github.io` |
| «Слишком много запросов» | Подождать минуту; общий IP школьной сети тоже учитывается |
| «Бесплатный лимит исчерпан» | Дождаться суточного обновления квоты |
| «Модель недоступна» | Модель и доступность на Free в актуальной документации Cloudflare |
| Ошибка сборки | Worker name `axioma-ai`, корень `/`, команда `npx wrangler deploy`; Wrangler не ниже 4.36.0 |
