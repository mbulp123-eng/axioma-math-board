# Аксиома — математическая доска

Интерактивная доска для уроков математики. Открывается без регистрации.

- Бесконечный холст, ручка и маркер, фигуры и текст.
- Перемещение доски правой кнопкой мыши, плавный масштаб и ползунок.
- Графики функций, включая обратные тригонометрические. Колесо над графиком меняет его внутренний масштаб, рамка — размер.
- Генератор заданий по математическим шаблонам с выбором темы, сложности и количества.
- Сохранение и открытие файлов `.axioma`, экспорт PNG и печать в PDF.

Доски сохраняются только в браузере посетителя. Совместного редактирования и облачной синхронизации нет. Генератор по темам работает локально по шаблонам.

## ИИ-помощник

Подготовлены панель помощника и серверный обработчик Cloudflare Workers AI:

- похожие задания по выделенному образцу с количеством, сложностью, диапазоном чисел и целыми ответами;
- распознавание фотографии или рукописного фрагмента;
- одна подсказка к следующему шагу;
- поиск возможной ошибки в решении;
- перевод на русский или казахский;
- свободный запрос по любой математической теме.

**Для настоящих ответов нужно один раз развернуть обработчик и указать его адрес.** Пока `AI_ENDPOINT` в `ai-config.js` пустой, интерфейс показывает «ИИ ещё не подключён» и ничего не отправляет. Инструкция: [cloudflare/SETUP.md](cloudflare/SETUP.md).

Выделите задание — рядом появятся действия. Либо откройте «ИИ-помощник» в верхней панели. Перед отправкой можно исправить исходный текст и убрать изображение. Отправляется только этот фрагмент и ваш запрос, а не вся доска. Результат сначала появляется в редактируемом предпросмотре. Ответы к заданиям скрыты; их можно добавить отдельным блоком. Добавление не меняет исходное задание и отменяется одной командой «Назад».

ИИ может ошибаться: проверяйте расчёты, диапазоны, перевод и распознавание. Формулы в `$…$`, `$$…$$`, `\\(…\\)`, `\\[…\\]`, а также распознанные обычные равенства и числа защищаются при переводе. Для сложных формул используйте явные математические разделители. Модель не является системой доказательства правильности решения.

## Публикация

Сайт состоит из статических HTML, CSS и JavaScript-файлов. Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Начальная страница — `index.html`. Сборка для GitHub Pages не требуется. `package.json` нужен для тестов и публикации серверной части в Cloudflare. Браузер не загружает Wrangler.

## Проверка

`npm test` — проверки доски, математики, вставки результатов, серверных ограничений и формата запросов/ответов. Вызовы модели в тестах заменены тестовым обработчиком; эти проверки не подтверждают качество реальных ответов или работу ещё не развёрнутого сервиса.


## Доработки надёжности

Описание изменений, выполненных проверок и ограничений находится в [RELIABILITY.md](RELIABILITY.md). Браузерные проверки: `npm run test:browser` после установки Playwright; также запускаются в GitHub Actions. Это не испытания на физических устройствах и не проверка качества живого ИИ.
